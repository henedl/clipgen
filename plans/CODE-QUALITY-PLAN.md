## How to work a batch

- One batch = one PR: `refactor:` or `chore:`, no version bump, no behavior change mixed in.
- Read each item's change and verifier note before editing. For revised items the change is the verifier's corrected proposal.
- `/check` before every commit. JS/CSS batches also run `/ui-check` and read the screenshots; CSS deletions need a before/after crop of each affected page, and a Safari look for WebKit-only styling.
- Moving or deleting a Python name: grep `mock.patch` targets in `tests/` and the `screenspace.py` / `workflows.py` facades.
