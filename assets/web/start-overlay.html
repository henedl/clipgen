  1. Set your folders. Input is where your source videos (and any .xlsx spreadsheets) live; output is where clips, screenshots, transcripts, and exports are written.
  2. Pick a spreadsheet.
    • Google Sheets: place a credentials.json OAuth client file in clipgen's working directory, then click Connect Google. Setup guide.
    • Excel: drop an .xlsx file into your input folder, or paste a full path.
  3. Choose a tool.
    • Studio — generate clips, screenshots, GIFs, and reels from the spreadsheet's timestamps.
    • Screenspace — frame-by-frame visual analysis of source videos. Works without a spreadsheet.
    • Transcripts — speech-to-text and AI summaries of source videos. Works without a spreadsheet.
